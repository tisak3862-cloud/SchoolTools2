# Учебный Центр

Бесплатная образовательная платформа с интерактивными калькуляторами, симуляторами и справочниками по математике, физике и информатике.

## Описание

Сайт создан, чтобы сделать учёбу понятнее: вместо сухих формул — живые инструменты, где можно посчитать, проверить и поэкспериментировать. Никакой регистрации, всё работает прямо в браузере.

## Запуск

Просто откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari). Сайт полностью статичный — не требует сервера, базы данных или интернета.

Для публикации в интернете загрузите `index.html` на любой хостинг:
- GitHub Pages
- Netlify
- Vercel
- Любой веб-сервер

## Разделы и инструменты

### Алгебра (15 инструментов)
- Калькулятор уравнений (линейных)
- Калькулятор дробей (сложение, вычитание, умножение, деление)
- Дискриминант и квадратные уравнения
- Калькулятор процентов
- Степени и корни
- Матрица 2×2 (определитель, след, обратная)
- Комплексные числа
- Тригонометрия (sin, cos, tan, arcsin, arccos)
- Упроститель выражений
- Разложение на множители
- Калькулятор пределов (численное приближение)
- График y = x²
- Система уравнений (2 линейных)
- Производная (численная)
- Интеграл (численное интегрирование)

### Геометрия (15 инструментов)
- Треугольник по сторонам (формула Герона)
- Окружность (площадь и длина)
- Теорема Пифагора
- Шар (объём и площадь поверхности)
- Прямоугольник (периметр, площадь, диагональ)
- Векторы (сложение, длина, скалярное произведение)
- Конус (объём и площадь боковой поверхности)
- Цилиндр (объём и полная площадь)
- Перевод углов (градусы ↔ радианы)
- Расстояние между точками
- Многоугольник (правильный)
- Трапеция
- Сектор круга
- Эллипс
- Куб

### Теория вероятностей (15 инструментов)
- Вероятность события
- Сочетания, размещения, перестановки
- Подбросить монетку (симуляция)
- Игральные кости (1–10 костей)
- Колесо фортуны
- Биномиальное распределение
- Нормальное распределение (с графиком)
- Статистика выборки (среднее, медиана, дисперсия)
- Дерево вероятностей (визуализация)
- Математическое ожидание
- Частота события
- Случайные числа
- Случайное блуждание (визуализация на canvas)
- Формула Байеса
- Равномерное распределение

### Физика (15 инструментов)
- Закон Ома (с мощностью)
- Энергия (кинетическая и потенциальная)
- Кинематика (равноускоренное движение)
- Конвертер единиц (длина, масса, температура)
- Маятник
- Гравитация (сила притяжения)
- Давление в жидкости
- Плотность
- Работа и мощность
- Волна (λ = v / f)
- Зеркало (фокусное расстояние)
- Сопротивление проводника
- Конденсатор
- Линза
- Теплоёмкость

### Информатика (15 инструментов)
- Перевод систем счисления (2, 8, 10, 16)
- Калькулятор объёма информации
- Логические операции (И, ИЛИ, НЕ, XOR)
- Таблица истинности
- Кодирование текста (ASCII)
- Алгоритмические структуры (справочник)
- Python-шпаргалка
- Сложность алгоритмов (справочник)
- Графы и деревья (справочник)
- Базы данных / SQL (справочник)
- Сети и адресация (IP + маска подсети)
- Шифр Цезаря
- Двоичное сложение
- Единицы измерения в IT (справочник)
- Временная сложность (оценка операций)
